## Run Locally

Start the local static server:

```bash
npm start
```

Then open `http://localhost:4173`.

Run the validation suite:

```bash
npm test
```

The app is intentionally dependency-free: HTML, CSS, browser JavaScript, and Node's built-in test runner.
